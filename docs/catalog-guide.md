# 导航使用说明

[打开算法手记](https://0raja.github.io/leetcode/) · [GitHub 题解索引](CATALOG.md) · [维护指南](maintenance.md)

## 查找和阅读

- 搜索题号、题名、题型或笔记内容，按练习范围、题型、难度和记录类型筛选。
- 打开题目后先回忆思路，再切换到原始笔记或高亮 Go 代码；可查看历史版本、打开原题和源码、复制代码或开启自动换行。
- 桌面支持全屏阅读；手机自动铺满屏幕，“本轮题目”展开目录。底部可切上一题、下一题，也可用 `Alt + ← / →` 切题、`Esc` 返回索引。
- 从列表进入时按筛选结果切题，从关联路径进入时按路线顺序切题；自评不会打断本轮顺序。“返回刚才的题”恢复目录、标签、源码版本和阅读位置。

## 比较相关题

“关联路径”是手工整理的比较建议，每一步说明状态、边界或解法发生了什么变化。详情同时提供按具体题型计算的自动关联，并标明来源；只有数组、字符串等宽泛标签相同的题不会因此被推荐。

## 保留复习记录

“需要再练”加入待复习，“能独立写出”移出队列；查看代码不会自动标为掌握。开始复习优先选择当前筛选结果中的待复习题，再参考自评时间选择。

标记和自评只保存在当前浏览器；换设备、浏览器，或从本地文件切换到线上地址前，先导出，再到新页面导入。导入合并已有标记，旧版导出文件仍可使用；清除自评不会删除待复习标记。

也可在本地直接打开 `docs/explorer/index.html`。数据反映最近生成时的仓库内容，不读取 LeetCode 在线状态；更新方式见[维护指南](maintenance.md)。
