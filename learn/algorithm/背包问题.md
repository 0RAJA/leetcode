# 背包问题

## 速查表

| **问题** | **dp 含义** | **转移**                  |
|--------|-----------|-------------------------|
| 是否存在   | 能否凑出 j    | `dp[j] \|\|= dp[j-w]`   |
| 方案数量   | 凑出 j 的方法数 | `dp[j] += dp[j-w]`      |
| 最大价值   | 容量 j 最大价值 | `max(dp[j], dp[j-w]+v)` |
| 最少数量   | 凑出 j 最少物品 | `min(dp[j], dp[j-w]+1)` |

然后再加：

| **物品使用次数** | **容量遍历** |
|------------|----------|
| 每件一次       | 倒序       |
| 无限使用       | 正序       |

计数问题再额外加：

| **计数类型** | **循环顺序** |
|----------|----------|
| 组合       | 物品 → 容量  |
| 排列       | 容量 → 物品  |

## 注意

1. dp[j] 的含义比公式更重要。

2. 每个物品只能一次 → 0-1 背包 → 倒序。

3. 每个物品无限使用 → 完全背包 → 正序。

4. 是否存在用 ||，计数用 +=，最值用 max/min。

5. 计数时：
   组合 → 物品外层；
   排列 → 容量外层。
