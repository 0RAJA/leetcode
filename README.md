# LeetCode · 题解与复习笔记

用 Go 记录题解，把题目、题型、代码和当时的思路连起来，方便以后回顾。

**[在线复习导航](https://0raja.github.io/leetcode/)** · **[GitHub 题解索引](docs/CATALOG.md)** · **[原始笔记](2026/README.md)** · **[个人博客](https://blog.humraja.top/)**

## 怎么使用

- 在导航中搜索和筛选题目，查看笔记与高亮代码；可全屏阅读、连续切题，或沿关联路径比较解法。
- 待复习和自评保存在当前浏览器，换设备前可导出、导入。详见[使用说明](docs/catalog-guide.md)。

## 怎么维护

继续写题解和原有笔记，提交并推送即可。GitHub Actions 自动生成索引、检查并发布导航；题目统计由导航根据题目记录计算。

- 标准题解：[`leetcode/editor/cn/pXXXX/`](leetcode/editor/cn/)。
- 路线练习与笔记：[`2026/`](2026/)。
- 历史实现：[`leetcode/editor/cn/_legacy/`](leetcode/editor/cn/_legacy/)。

日常流程、需要修改的文件及本地预览，见 **[维护指南](docs/maintenance.md)**。
